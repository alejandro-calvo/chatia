Ayuda

¿Qué es ChatIA?

ChatIA es una aplicación web de chat con inteligencia artificial hecha con Django. La idea es poder crear conversaciones, escribir preguntas y guardar el historial para poder volver a consultarlo más adelante.

Funciona de forma parecida a un chat normal: tú escribes un mensaje, la IA responde y la conversación se va guardando automáticamente.

¿Cómo se usan los chats?

Desde la sección Chats puedes crear una conversación nueva. Cada conversación tiene su propio título y sus propios mensajes, así que puedes separar tus dudas por temas.

Por ejemplo, puedes tener un chat para dudas de Django, otro para estudiar un examen y otro para pedir ayuda con código.

También puedes volver a conversaciones anteriores, renombrarlas o borrarlas si ya no las necesitas.

Configuración del usuario

En la página de Configuración puedes cambiar algunos datos de tu perfil, como el alias, el modelo por defecto y la temperatura.

Además, puedes personalizar el aspecto del chat: el color de tus mensajes, el color de los mensajes de la IA, el color de la letra y el tipo de letra. Así cada usuario puede tener el chat un poco a su gusto.

¿Qué es la temperatura?

La temperatura es un valor que cambia la forma en la que responde la IA. Si la temperatura es baja, la respuesta suele ser más directa, seria y predecible. Si la temperatura es más alta, la IA puede responder de forma más creativa y variada.

Por ejemplo, para preguntas técnicas o código puede venir mejor una temperatura baja. Para pedir ideas, textos o respuestas más abiertas, puede ser más útil una temperatura un poco más alta.

En esta aplicación cada usuario puede guardar su temperatura preferida desde Configuración. Ese valor se usa cuando se envían mensajes a la IA.

Perfil

En la página de Perfil puedes ver tus datos guardados, tu configuración actual y algunas estadísticas, como el número de chats y mensajes que tienes.

Tecnologías usadas

Esta práctica está hecha con Django para la parte del servidor, SQLite para guardar los datos, Bootstrap para la maquetación y HTMX para actualizar el chat sin recargar toda la página.

También se usa una API externa de inteligencia artificial para generar las respuestas del chat.

Consejos de uso

  • Crea una conversación distinta para cada tema importante.
  • Usa títulos claros para encontrar tus chats más rápido.
  • Si una conversación ya no te sirve, puedes borrarla desde la lista de chats.
  • Si quieres cambiar el aspecto del chat, ve a Configuración.
  • Si quieres respuestas más serias, usa una temperatura baja.
  • Si quieres respuestas más creativas, prueba con una temperatura más alta.

En resumen: entra en Chats, crea una conversación y empieza a preguntar.
